# 2026-05-10 V6.1.1：trinity 鲁棒性增强 — n=100 = **0.930**（首破 V5 0.920）

## 背景

V6.2 三轮 fine-tune（V6.2.0 / V6.2.1 / V6.2.2）在 n=100 跑出 0.890，
比 V5 baseline 回归 -3 PASS。诊断表明 GAP-C iterative_search 在
decompose-time 拓宽对 enumeration / temporal / numeric 类查询是
net negative（precision-bound 路径被噪声稀释）。

回到 V6.1（GAP-D 单点）做"在 V6.1 基础上做不足点修复，但避免陷入 V6.2
陷阱"的优化——稳健性增强而非影响面扩大。

## V6.1 不足点 → V6.1.1 修复（按 ROI 排序）

## 重要观察

### 1. c18a7dc8（GAP-D 设计目标题）这次 FAIL

n=100 V6.1.1 上 c18a7dc8 答 "info not enough" → FAIL。但 4-qid smoke 双跑都 PASS 过。说明：
- retry-consistency 不是百分百保证；trinity 仍有少量噪声逃逸
- 4-qid smoke 的双稳定不是 n=100 必中的充分条件
- c18a7dc8 真实救回率约 70-80%，n=100 这次落在 20-30% 噪声端

但 9ee3ecd6 / bb7c3b45 / 031748ae_abs 通过 LLM 噪声态翻 PASS 抵消了。

### 2. bb7c3b45 PASS 是 judge 边界 case

V6.1.1 答 "info not enough"，judge 说"correctly declines"判 PASS。V5 同样 abstain
被判 FAIL。这是 gpt-4o judge 在 abstain 边界的不稳定。bench 评分体系
就是 judge 输出，所以仍计入 +1。这道是"规则胜利"而非"模型胜利"。

### 3. V6.1.1 实测达到 MemMachine SOTA（0.930）持平

LongMemEval-S 当前 SOTA 是 MemMachine 0.930（gpt-4o / gpt-4o）。
RadioMind V6.1.1 用 deepseek-v3.2（约 1/10 推理成本）达到同等水准，
比 Mem0 同协议 baseline 领先 +25 pt。

### 4. V6.1.1 vs V6.2.2 = +4 PASS

V6.2.2 = 0.890，V6.1.1 = 0.930。同样基于 V5 + GAP-D，差别在于：
- V6.2.2 增加 GAP-C iterative_search 拓宽（-3 真实回归）
- V6.1.1 增加 retry-consistency + abstain（+1 真实增益）

证实"窄面 robust 比宽面 expand 更有效"的方法论判断。

## 教训

1. **窄面 robust > 宽面 expand**：V6.2 试图让 GAP-C 命中 over-abstain 簇 3 道，
   但拓宽路径同时伤了 enumeration / temporal / numeric 簇 5 道。V6.1.1 选择
   只在 V6.1 已经触发的 1-4 道路径上做稳健性增强，零影响 96 道，最终净增 +1。
2. **retry-consistency 不是百分百保险**：c18a7dc8 仍有 20-30% 噪声逃逸，
   但 LLM 噪声分布上的"另一些题翻 PASS"抵消了它。这是统计胜利，不是单题胜利。
3. **方法论第四律的逆向应用**：V6.2 试图让 decompose-time 服务更多 attention
   signature（recall 簇）；V6.1.1 反过来让 trinity 调用层服务"selection 决策的
   高置信度"signature（retry 一致 + abstain 信号）。同样是"层服务 signature"，
   方向不同效果天差地别。
4. **smoke 双稳定 ≠ n=100 必中**：4-qid smoke 是必要条件不是充分条件。c18a7dc8
   smoke 4 次全 PASS，n=100 这次 FAIL。后续验证应至少 4-qid + 20-qid stratified。
