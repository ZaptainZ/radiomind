## 关键架构升级（v3 → v5）

v4 → v5 之间的所有改动都基于**两条诊断**：
1. v4 引入的 BidirectionalAbstainGate "每题 trinity"导致 7 道 over-abstain 回归
2. multi-round trinity 对 inference qtype 是 divergent task，不该用

诊断后落地的 6 项架构升级：

| # | 升级 | 文件 | 应用方法论 | 修了哪些 |
|---|---|---|---|---|
| 1 | abstain gate 加 looks_abstained guard | salvage.py | 借鉴 v3 克制 | -7 over-abstain 不再误伤 |
| 2 | multi-round 仅 date qtype | mind.answer_hint | 收敛/发散区分 | -1 inference drift |
| 3 | iterative_search（多锚点 attention） | mind.iterative_search | 多方 + 多轮 | preference recall 改善 |
| 4 | 子三体（depth=1） in skill validates | trinity.py + skills | 多层 | temporal +23.5pt 关键 |
| 5 | atom-level trinity scope filter | mind._trinity_filter_atoms | 维度型三体 | multi-session +5.6pt |
| 6 | NER 第 3 抽取源 | numeric_aggregator._extract_ner_entities | 真三方表决 | d851d5ba 终于 PASS |

## 关键里程碑

1. **`d851d5ba` (chronic charity sum) 在 v5 第一次 PASS** —— 这道题在 v3
   v4 都失败，反复修都没救回；v5 通过 NER 第三源 + iterative_search +
   multi-round trinity 联合救回。
2. **temporal-reasoning +23.5pt** —— 多轮 trinity 对日期算术的正确应用是
   单点最大涨幅。
3. **0.920 距 MemMachine SOTA 0.930 仅 1pt** —— deepseek-v3.2 1/10 成本下
   接近 SOTA，证明架构投入比模型升级更划算。
4. **跨 session 多步推理（multi-session）从 0.722 → 0.778** —— atom
   filter + NER 把"分散在多 session 的事件"召回率推上去。

## 应用的核心方法论原则全套

| 原则 | 实施 |
|---|---|
| Trinity 多方（n_stances） | iterative_search 用 N-party 生成 N 个扩展 query |
| Trinity 多轮（max_rounds） | answer_hint date qtype = 3 round；age/event_interval = 3 round |
| Trinity 多层（sub_trinity_depth） | age/event_interval _validate = depth=1 |
| 维度型 stance 命名（不要结论型） | 全部 trinity 调用都遵守此规则 |
| 收敛/发散区分（多轮只用于收敛） | divergent tasks（class promotion / refine_amount_events / abstain）保持单轮 |
| 注意力 wants 信号驱动路由 | preference_anchor / temporal_constraint / focus 各自路由 |
| 工程层与方法论分离 | errata filter / NumericAggregator / scope filter 是工程层；trinity/attention 是方法论 |
